dictionary tool. Open youddao.com in any modern browser and use it right away

## What Youddao can do

- **Text translation** — translate short texts and sentences across multiple
  languages; the language selector on the homepage lists the available pairs.
- **Smart dictionary** — look up words with clear definitions, parts of
  speech, and real example sentences, in a single search box.
- **Document summarization** — paste long text and get a concise summary,
  useful for articles, reports, and study notes.
- **Free and zero-setup** — core features are free; nothing to install or
  configure. Works in any modern desktop or mobile browser, including shared
  or public computers.

## Who Youddao is for

Youddao is designed for lightweight, everyday use:

- Students and language learners who want fast word lookups and example
  sentences while reading.
- Anyone who needs quick short-text translation without downloading a client
  or creating an account.
- Readers who want to skim long articles via summaries.
- People working on shared or public computers who cannot install software.
- Users looking for a clean, focused interface instead of a heavyweight
  translation suite.

## FAQ

**What is Youddao?**
Youddao is a free online AI translation and smart dictionary tool at
youddao.com. It supports text translation, word lookup with definitions and
examples, and document summarization, and it runs entirely in the browser —
no download and no account required.

**Is Youddao the same as Youdao (有道)?**
No. Despite the similar name, Youddao is an independent brand with no
affiliation, endorsement, or partnership with NetEase Youdao or its Youdao
Translate product. The similar spelling is coincidental.

**Is Youddao free?**
Yes, Youddao's core translation and dictionary features are free to use in
the browser.

**Do I need to install an app?**
No. Youddao is a web app: open youddao.com in any modern browser and start
using it, including on shared or public computers.

**What languages does Youddao support?**
Youddao focuses on everyday translation scenarios and supports multiple
languages. Check the language selector on the homepage for the current
language pairs.
